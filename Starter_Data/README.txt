# Starter Data Pack — Hackathon Case Fixtures
## Fynd × NMIMS Hyderabad Hackathon

This directory contains official synthetic problem fixtures for Hackathon Cases C01 to C35.
All records are synthetic benchmark fixtures designed for reproducibility and public testing.

Key principles:
1. All fixtures are synthetic, version-controlled reference datasets.
2. `expected_topics` or reference labels are ground-truth data for evaluation only.
3. Classifiers and AI inference must never consume reference labels as prediction inputs.
4. Default currency is INR unless explicitly noted.
